# 🧾 Vrinda Store – Sales Data Analysis Project (Excel Dashboard)

This project is a sales data analysis of **Vrinda Store**, a general retail shop. The analysis was done using **Microsoft Excel**, where raw sales data was cleaned, processed, and visualized using an **interactive dashboard** with slicers, charts, and key performance indicators (KPIs).

## 📌 Project Overview

The goal of this project was to gain insights into the store’s sales performance, popular products, and customer trends through interactive visualizations. It is a beginner-friendly data analytics project and was created by following a YouTube tutorial by **Rishabh Mishra**.

## 🎯 Objectives

- Understand and analyze the sales performance of Vrinda Store.
- Use Excel functions and PivotTables for data cleaning and summary.
- Build a fully interactive Excel dashboard using slicers and charts.
- Identify sales trends, top-selling products, and customer patterns.

## 📂 Files Included

- `vrinda_dashboard.xlsx` – Final Excel file with interactive dashboard.
- `README.md` – This documentation file.



## 🛠 Tools & Skills Used

- **Microsoft Excel**
  - PivotTables
  - PivotCharts
  - Slicers
  - Excel formulas (SUMIF, COUNTIF, etc.)
  - Conditional Formatting

## 💡 Key Insights

- Top-performing product categories and items.
- Monthly sales trends and revenue breakdowns.
- Customer segment analysis.
- Store performance by region/area (if applicable).

## 📚 Learnings

- How to use Excel as a powerful data analysis tool.
- Creating interactive dashboards without using advanced BI tools.
- Structuring raw data for better analysis and visualization.
- Improving report presentation for stakeholders.
